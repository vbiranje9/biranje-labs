# Biranje Labs

The engineering portfolio of Vishal Biranje and the foundation for future Biranje Labs services, products, and case studies.

## Free Hosting: GitHub Pages

This static site deploys automatically with the workflow in `.github/workflows/deploy-pages.yml`.

1. Create a public GitHub repository named `biranje-labs`.
2. Push this project to its `main` branch.
3. In the repository, open **Settings > Pages** and select **GitHub Actions** as the source.
4. The first deployment publishes at `https://<github-username>.github.io/biranje-labs/`.

For a custom domain later, add a `CNAME` file and configure the domain's DNS records in GitHub Pages settings.
