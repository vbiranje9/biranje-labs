# Portfolio Media

The portfolio automatically shows the original uploaded images when these files are present:

- `vishal-biranje-portrait.png` - Vishal Biranje's profile photograph.
- `bmw-exemplary-performer-award.png` - BMW TechWorks India Exemplary Performer Award certificate.

Until the original files are placed here, the site intentionally renders animated visual fallbacks rather than broken images. Once both source files exist, set each matching `data-media-enabled` value in `index.html` from `false` to `true`.
